# 📊 Retail Sales Analysis using PostgreSQL

## 📌 Project Overview

This project demonstrates a complete **Retail Sales Analysis** using **PostgreSQL** and **Microsoft Excel**. The objective is to analyze retail transaction data, clean and prepare the dataset, and answer real-world business questions using SQL.

The project covers the complete workflow from importing raw Excel data into PostgreSQL, performing data cleaning, exploratory data analysis (EDA), and generating business insights using SQL queries.

---

# 🎯 Project Objectives

- Import retail sales data from an Excel dataset into PostgreSQL.
- Perform data cleaning and validation.
- Explore customer purchasing behavior.
- Analyze sales trends using SQL.
- Generate actionable business insights.

---

# 📂 Dataset

The dataset contains retail transaction records including:

- Transaction ID
- Sale Date
- Sale Time
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price Per Unit
- Cost of Goods Sold (COGS)
- Total Sale

The source dataset was maintained in **Microsoft Excel** and imported into **PostgreSQL** for analysis.
